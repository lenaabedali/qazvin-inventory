# Inventory 3D

The Coco Code / Tamara inventory tutorial, rebuilt for a 3D third-person game, styled after the carved stone bags restored from Qazvin.

## Quick start
1. Import `Inventory3D.unitypackage` (Assets > Import Package > Custom Package), or unzip into your `Assets` folder.
2. Menu: **Tools > Inventory 3D > Build Demo Scene**, then press Play.

| Key | Action |
|---|---|
| Mouse / WASD / Space | Orbit camera / move / jump |
| Tab or I | Open/close inventory (Esc or click the dark background also closes) |
| 1-7 / scroll wheel | Select toolbar slot |
| Left click | Break the block under the crosshair (shovel = grass, pickaxe = stone, axe = wood) |
| Right click | Place the selected block |
| Q | Drop one of the selected item |

## Stone style
- The inventory panels, slots and the handle arch over the main inventory are carved-stone sprites generated by the builder (`Generated/Stone UI`). The selected slot gets a turquoise inlay.
- The character carries a 3D **Stone Bag** (bell-shaped slab with a handle opening, diamond band and engraved arch) that swings as you walk (`BagSway`).
- To give your own character the bag: select it (or its hand bone) and use **Tools > Inventory 3D > Add Stone Bag To Selected Character**, then move *Bag Pivot* to the hand.
- Change the look in `Editor/StoneTextures.cs` (colors, carvings) and `Editor/StoneStyle.cs` (bag proportions), then rebuild.

## Adding it to your own game
1. **Tools > Inventory 3D > Add Inventory UI To Current Scene** builds the canvas, toolbar, main inventory and manager (video chapters 1-3).
2. Tag your player `Player` and add **ItemUser** to it. Set **Cam** to your camera and **Player** to your character (so the aim ray skips your own character and reach is measured from the player). Add **ItemHolder** to your character's hand bone.
3. On *Inventory Manager*, drag your camera / movement scripts into **InventoryToggle > Disable While Open**, and fill **Start Items**.
4. Make items: right-click in Project > **Create > Inventory 3D > Item**. Blocks need a 1x1x1 `worldPrefab` with a **Breakable** component.
5. Grid placement assumes blocks are centered on whole numbers, so make your ground's top surface sit at y = -0.5 (or turn off *Snap To Grid* on ItemUser).
